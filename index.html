④ 상담유형 Excel

Firestore 확인 중...
※ Excel 시트명: 2026_CALL / 2026_ERMS / 2025_CALL / 2025_ERMS 형식
※ CALL = 인바운드 상담 / ERMS = 게시판 상담
※ 각 시트 컬럼: 대분류 / 중분류 / 소분류 / 코드▼ / 문의 유형 / 1월 ~ 12월
※ 연도별·채널별 월간 시트를 한 파일에서 누적 관리하며, 빈 월은 미등록으로 처리합니다.
※ 특정기간 비교는 올해_CALL / 올해_ERMS / 전년_CALL / 전년_ERMS 4개 시트로 구분해 등록합니다.
※ 학년정보(고1/고2/고3/N수/기타/비회원)는 CALL 데이터에 한해 2026년부터 적용하며, ERMS·스마트러닝에는 적용하지 않습니다.
※ 2026_CALL 월간 시트는 2단 헤더를 지원합니다: 1월~12월(상위) → 문의량 / 고1 / 고2 / 고3 / N수 / 기타 / 비회원(하위).
※ 기간 시트 컬럼: 시작일 / 종료일 / 대분류 / 중분류 / 소분류 / 코드▼ / 문의 유형 / 건수 / 고1 / 고2 / 고3 / N수 / 기타 / 비회원
※ 분석명은 사용하지 않습니다. 기간 시트만 별도로 업로드해도 기존 월간 데이터는 유지되며, 같은 비교구분·채널 조합은 최신 기간으로 갱신됩니다.
